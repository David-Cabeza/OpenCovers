Política de privacidad

Última actualización: 16 de noviembre de 2026.

Resumen

La web opencovers.dev no tiene cuentas, formularios, analítica ni cookies propias. OpenCovers no recoge datos personales de quienes la visitan.

Qué ve cada servicio al visitar la web

  • GitHub Pages aloja la web. Como cualquier servidor, GitHub puede registrar la dirección IP y los datos técnicos de la petición. Consulta la declaración de privacidad de GitHub.
  • Google Fonts sirve las tipografías, por lo que tu navegador se conecta a los servidores de Google para descargarlas. Consulta la política de privacidad de Google.
  • API pública de GitHub: la página consulta desde tu navegador datos públicos del repositorio, como el número de estrellas. GitHub ve esa petición.

OpenCovers no recibe ni almacena ninguno de esos datos.

Herramientas de analítica de búsqueda

El responsable del proyecto usa Google Search Console y Bing Webmaster Tools para saber cómo aparece la web en los buscadores. Esos servicios muestran datos agregados de búsqueda sobre el dominio opencovers.dev y no identifican a visitantes concretos.

El software OpenCovers

OpenCovers es un motor de reservas de código abierto que cada restaurante instala en su propia infraestructura. Quien lo instala es el responsable de los datos de sus clientes. Este proyecto no tiene acceso a ellos. Esta política solo cubre la web opencovers.dev.

Contacto

Para cualquier duda sobre privacidad, abre una incidencia en github.com/David-Cabeza/OpenCovers.
