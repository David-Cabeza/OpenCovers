OpenCovers

OpenCovers is an open source reservation engine for restaurants. It handles availability, bookings, tables and a signed event feed. You use it through an HTTP API or an MCP server.

The same engine runs a staff app (agenda, availability, floor plan and setup, in Spanish and English) and a booking widget a venue embeds on its own site, in seven languages (five of them machine-assisted and waiting for native review) and a light or dark look.

Status: pre-alpha. The engine, the staff app and the MCP server run locally and pass their tests, and the booking widget is in progress. 70 of the 78 conformance cases pass and 8 are partial. Not built yet: payments, SMS and WhatsApp, reminders, a guest screen in the staff app and POS adapters. License: Apache-2.0. Stack: Node.js, Hono, Drizzle and PostgreSQL.

Source code on GitHub

Guarantees

  • One transaction decides availability and booking.
  • PostgreSQL enforces no double booking with a GiST exclusion constraint. Application code does not.
  • Every write carries an idempotency key and produces a monotonic version.
  • Venue data is isolated. A request for another venue returns not found.
  • The engine stores the minimum guest data a booking needs. Erasure returns counts and keeps hashes, not personal values.
  • Webhooks are signed. They push events from the venue's event feed to your HTTPS endpoint.

HTTP API

The API lives under /v1. It is described in an OpenAPI contract. Errors use a fixed vocabulary, listed in errors.md. The contract and its conformance cases come before the implementation. Webhooks are documented separately.

MCP server

The MCP server exposes 18 tools over stdio: reservation.*, waitlist.* and venue.*. It wraps the HTTP API. It is published on npm as @opencovers/mcp and listed in the official MCP registry as io.github.David-Cabeza/opencovers.

npx -y @opencovers/mcp

Create an agent key in the staff app under Setup, API keys. See the MCP contract and the package README.

Run it locally

You need Node.js 22.9 or newer, pnpm and Docker.

git clone https://github.com/David-Cabeza/OpenCovers.git
cd OpenCovers
docker compose up -d   # PostgreSQL
pnpm install
pnpm db:migrate
pnpm dev               # API :3000 · staff app :5173 · site :5174

Open http://localhost:5173, sign up and create a venue.
